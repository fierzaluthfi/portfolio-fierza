## Overview

Website portfolio interaktif yang memadukan estetika antarmuka grafis dari **Persona 3 Reload (P3R)** dan **Soul Hackers 2 (SH2)** dalam palet **Black & White (Monokrom Kontras Tinggi)**. Dirancang dengan presisi untuk menyajikan riwayat operasional, administrasi data, dukungan sistem IT, dan portofolio profesional secara mendalam dan berdaya baca tinggi.

## Key Features

- **Atlus Synthetic Web Audio SFX**: Audio sintetis in-memory (Web Audio API) untuk interaksi taktis tanpa ketergantungan file audio eksternal (dapat di-mute).
- **Aion Hexagonal Radar Canvas**: Visualisasi 6 dimensi kompetensi teknis berbasis HTML5 Canvas.
- **Combat Mission Log**: Dokumentasi 8 riwayat penugasan profesional dengan filter kategori (Akademik, Enterprise, Publik).
- **Keyboard Tactical Shortcuts**: Tekan angka `1` sampai `7` pada keyboard untuk melompat cepat ke masing-masing modul.
- **Print & PDF Export Ready**: Dilengkapi print stylesheet bersih untuk cetak fisik maupun ekspor PDF.
- **One-Click Buffer Copy**: Fitur salin kontak instan dengan notifikasi toast ala Persona.

## Deployment & Hosting

Website ini di-host secara gratis menggunakan **GitHub Pages**.
Alur deployment otomatis dikonfigurasi melalui GitHub Actions pada file [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
